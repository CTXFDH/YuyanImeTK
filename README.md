本项目基于语燕输入法，由gemini修改完成，本人不会编程hello world都不会。


## 详解设置
1，主题

   新增主题编辑，导入导出功能，主题文件后缀.yus
   
  主题编辑划分了若干个分区，点哪里就可以修改哪里的颜色，长按设置项标题可以直接复制色值，可diy的有很多，如果想单独修改输入区的某个按键颜色，只能在data里找到theme，修改json文件，可以参考{炫彩彩虹拼盘.yus}这个主题是怎么做的。

2，按键效果

   新增按键音效的开启时段设置，防止晚上扰民。增加了按键音效选择，从微信，百毒中提取了音效文件

3，键盘设置

   新增持机习惯，如果设置左手持机，那么展开这叠候选词，关闭联想的按钮都会放到左边。
   
   新增乱序17 中筛  左删的布局开关

4，输入设置

   新增拼音全键键盘小写，对小学生友好
   
   新增中文联想模式-单次联想
   
   中英混输  支持中文9键和乱序17 的中英混输

5，语音识别设置

   新增离线语音输入
   
   需要在设置项里有离线模型的下载地址，导入即可使用。
   
   [按住说话]键上边的空白长条，左右滑动可以移动光标位置

6，个性化短语

   新增功能

##  其他改善

4，表情，符号界面重构
